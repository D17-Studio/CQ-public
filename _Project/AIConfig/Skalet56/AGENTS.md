AI agents 协作约定，对 Claude Code 及任何 IDE AI 代理生效。

## 我的习惯

- Unity 开发经验丰富，但 .NET/Avalonia 桌面开发刚入门
- 用 Rider IDE，重命名任务交给我做（Ctrl+RR 零残留），你写代码逻辑

## 协作方式

- **先讨论再动手**（请重点记忆）：如果我没有明确说"请修改代码""开始写吧"之类的话，不要动手写文件，而是说明你打算怎么写、改哪些地方，等我确认
- **核心逻辑先讨论，简单功能直接做**：架构设计、核心算法等我想要深入了解的部分，先讨论方案再实现；而 dotnet 交互操作、界面显示等我不太想深究的细节，可以直接写，但请简单说明这个功能的大致流程和原理
- **追问澄清**：我描述不够精确时追问，不要自行脑补发挥
- **不写我没要求的代码**：只完成当前任务，不写"顺便"的功能
- **对我的想法大胆质疑**：提出更好方案、反驳不合理之处。不要一味认同

## 编码偏好

### 注释

- **写新功能时要多写注释**，说明逻辑、原理
- 注释用中文
- 类级别和公开方法加说明注释
- 涉及 .NET/Avalonia API 操作时，简单注释说明该 API 的功能，因为我不熟悉 .NET 开发

### 修改规则

- 不随意修改原有代码
- 每次新增/修改/删除必须告知具体位置

### 命名与风格
- 命名优先简洁，对齐现有风格
- 外部公开的方法带 `<summary>` 注释
- 内部私有方法和方法名本身就解释清楚的，可以不加注释
