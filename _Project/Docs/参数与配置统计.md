## 五、问题清单（按优先级）

1. **HitEffect 预制体字段失配**
   代码为 `_baseScale/_growth`（`HitEffect.cs:10-11`），预制体仍存 `_startScale: 1` / `_endScale: 3`（`HitEffect.prefab:92-93`）。当前值等于代码默认值所以无感，一旦调值会失效。

2. **NoteView 代码默认值与预制体单位不一致**
   代码默认 20f（设计像素），预制体 0.3（世界单位）。相机正交尺寸 5、1080p 下 1 世界单位≈108px，0.3≈32px。新建预制体沿用代码默认会得到约 66 倍大的 Note。建议删默认值或统一为 0.3 并注明单位。

3. **轨道拓扑散落 7 处**
   `LaneCount=7`、`[-3,3]` 应提取共享常量；至少公开复用 `InputService` 的常量。

4. **MusicService 注释与常量矛盾**
   `MusicService.cs:76` 写 1000ms 淡出，实际 `StopFadeMs = 500`。

5. **计分权重与评级表不可调**
   权重/阈值硬编码在 `ScoringSystem.cs`；`readonly` 字典内容仍可变，但策划无法改配置。

6. **`ScreenAdapter.ToScreenPos` 未做分辨率换算**
   与 `ToWorldPos` 不对称，非 1080p 下 VFX 位置会偏。

7. **`DotView._missFadeDurationMs` 无代码默认值**
   仅靠预制体赋值，漏配即瞬间消失（0ms）。

8. **HMAC 密钥硬编码**
   `ScoreArchiveKey.cs:4` 的 `Secret` 编入程序集，只能防轻度篡改，不应视为安全配置。
